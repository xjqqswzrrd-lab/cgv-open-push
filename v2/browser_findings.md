# CGV 영화별 예매 화면 확인

확인 시각: 2026-08-14

- 실제 사용자가 보는 시작 URL은 `https://cgv.co.kr/cnm/movieBook/movie`이다.
- 극장 선택은 URL 이동이 아니라 페이지 내부 모달/상태 변경으로 진행된다.
- 화면 흐름은 `+` 버튼 → 극장 검색 입력 → 검색 결과 지점 선택 → `극장선택` 확정 → 영화 카드 `오디세이` 선택 → 날짜 스트립 확인이다.
- 이전 구현이 사용한 `/cnm/movieBook/cinema?siteNm=...&siteNo=...`는 사용자가 제공한 영화별 예매 화면과 다른 경로다.
- 자동화는 URL 파라미터로 지점을 바꾸지 말고 실제 UI 클릭을 재현해야 한다.
- 날짜는 전체 DOM의 날짜가 아니라 날짜 스트립 안에서 실제로 보이는 버튼 중 가장 오른쪽 버튼을 읽어야 한다.
- 사용자 화면에서 용산아이파크몰의 마지막 날짜는 8월 25일로 확인되었으므로, 자동화가 9월 2일을 읽으면 실패로 처리해야 한다.
- 날짜/극장/영화 선택 검증에 실패하면 상태를 갱신하거나 알림을 보내면 안 된다.

## 현재 브라우저 HTML

`/home/ubuntu/browser_html/cgv_co_kr_movie_1786687971539.html`

이 파일은 DOM 셀렉터 분석에 사용한다.

## 구현 결론

Playwright UI 시나리오 자동화가 적합하다. 셀렉터는 좌표가 아니라 버튼/입력 의미와 텍스트를 기준으로 찾고, 각 클릭 후 기대 상태를 검증해야 한다. 날짜 추출은 `getBoundingClientRect()` 및 표시 상태를 기준으로 화면 내 오른쪽 끝만 선택한다.

## 주의

기존 Cloud Run 배포본은 `/cinema` 경로를 읽고 있으므로 사용자 화면과 동일한 감시본이 아니다. 수정 전까지 유효한 감시 상태로 간주하지 않는다.

## 실제 UI 클릭 검증 추가

브라우저에서 확인한 실제 흐름:

1. `/cnm/movieBook/movie` 접속.
2. `button.cnms01648_titleLink__rHoLt` 텍스트 `극장별 예매` 클릭.
3. 극장 모달이 열리고 `input#search1` placeholder `극장명을 입력해주세요` 표시.
4. `용산아이파크몰` 입력 후 검색 결과 버튼 텍스트가 정확히 `용산아이파크몰`로 표시.
5. 결과 버튼 클릭 시 선택된 극장 상태가 본문에 표시되고 URL은 `/cnm/movieBook/cinema`로 바뀐다. 이 시점에는 영화가 아직 선택되지 않았으며 날짜가 9월 2일까지 보일 수 있다.
6. `영화별 예매` 버튼을 클릭하면 영화 선택 모달이 열린다.
7. 오디세이 카드는 `button` 내부 `img[alt*="오디세이"]`와 텍스트 `오디세이`로 정확히 식별 가능하다.
8. 오디세이 카드 클릭 후에야 사용자가 보는 특정 영화 기준의 날짜/상영 정보가 렌더링된다.

중요한 결론: 기존 구현이 `/cinema?siteNo=0013`를 직접 열었던 것은 극장만 선택된 상태이고 영화 오디세이를 선택하지 않은 상태를 읽은 것이다. 따라서 9월 2일을 읽은 원인이 확인되었다. 올바른 자동화는 `/movie`에서 UI를 통해 극장 선택 후 `영화별 예매` → `오디세이`를 클릭해야 한다.
